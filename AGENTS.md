# Instrucoes do projeto

- Este e o repositorio oficial do trabalho final: https://github.com/devmmar/trabalho-final-pw4.git.
- Todas as alteracoes, commits e pushes do trabalho final devem usar este repositorio. Nao usar devmmar/PWIV como destino do trabalho final.
- Autor e proprietario: Vitor Machado Marques (devmmar). Preservar a autoria configurada no Git.
- Nao usar nomes de assistentes ou ferramentas como autoria, prefixo de branch, nome de projeto ou assinatura. Para novas branches, usar nomes como feat/nome-da-funcionalidade ou fix/nome-da-correcao.
- Frontend em frontend/, backend em backend/ e Docker Compose na raiz.
- Consultar README.md e DOCKER.md antes de alterar caminhos ou comandos de execucao.
- Manter .env, senhas, volumes, backups, node_modules e artefatos de build fora do Git.
- Validar frontend com npm run build; testes do backend exigem banco ativo.
